# Kaushik Sridhar — Portfolio

Personal portfolio site, live at https://kaushiksridhar17.github.io/KaushikSridhar/

Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

## Files

- index.html — all page content
- styles.css — colours, type and layout (follows the visitor's light or dark system setting)
- script.js — keeps the footer year current
- resume.pdf — the resume linked from the site
- iamneo.pdf — iamneo internship completion letter, linked from Experience
- favicon.svg — browser tab icon
- .nojekyll — tells GitHub Pages to serve the files as they are

## Updating

To change content, edit index.html. To update the resume, replace resume.pdf with a file of the same name. Commit and push, and GitHub Pages republishes in about a minute.

## Preview locally

    python3 -m http.server 8000

Then open http://localhost:8000
